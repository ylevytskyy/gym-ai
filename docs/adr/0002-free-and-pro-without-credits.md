# 0002. Free tier and Pro subscription, without credits

Status: accepted, 2026-11-13.

Aura Fit earns money through one Pro subscription ($2.99 / month, $24.99 / year, 7-day trial on both)
on top of a useful free tier. AI use is limited for free users by a daily allowance that resets, not
by a credit balance, and the paywall opens only when the user asks for a Pro feature. The model costs
about $0.0003 per coach message and $0.003 per plan, so credits would add a visible counter and
purchase flow to protect almost no cost.

Alternatives: credit packs alongside Pro (the earlier draft; rejected as a "wallet that runs out" for
a near-free resource); subscription only with a hard paywall after onboarding (rejected: pushes away
people who have not seen value yet). Revisit if a pricier model raises cost per active free user
above $0.50 a month.
